# ข้าวแกง 40 — Streamlit V2

แอปจัดเมนูหมุนเวียน 3–5 เมนูต่อวัน วางแผน 7–30 วัน คลังเมนูร้านและภายนอก ค้นหาเว็บผ่าน Bing RSS (หากบริการเข้าถึงได้) และบันทึกลิงก์สูตรเอง **พักระบบต้นทุนไว้ก่อน**

## อัปเดต GitHub เดิม
1. เปิด repository `khaokaeng40` บน github.com ผ่าน Chrome
2. อัปโหลด `app.py`, `requirements.txt`, `README.md` จาก ZIP นี้ไปที่ราก repository เดิม โดยยืนยันการแทนที่ไฟล์ชื่อซ้ำ หรือเปิดไฟล์แต่ละรายการและกด Edit เพื่อแทนที่เนื้อหา
3. Commit changes ไปที่ `main` แล้ว Streamlit Cloud จะ deploy ใหม่อัตโนมัติ
4. รีเฟรชเว็บแอป รอจนเห็น `V2` ด้านใต้ชื่อแอป

## สำคัญ
- สำรองข้อมูล V1 เป็น JSON **ก่อนอัปเดต**; V2 นำเข้า JSON ของ V1 ได้ (ข้อมูลวัตถุดิบ/ต้นทุนของ V1 ไม่ถูกนำมาใช้งานใน V2)
- ข้อมูลที่แก้ไขใน Streamlit session ไม่ถาวร ดาวน์โหลดสำรอง JSON หลังจัดตารางหรือแก้สูตร และนำเข้ากลับเมื่อเริ่มเซสชันใหม่
- ระบบค้นหาอัตโนมัติพึ่งผล Bing RSS ซึ่งอาจถูกจำกัดหรือเปลี่ยนแปลง มีปุ่มเปิด Google/YouTube เป็นทางเลือกเสมอ
- การค้นหาเป็นการเก็บลิงก์ ไม่ได้คัดลอกสูตรทั้งหมดโดยอัตโนมัติ
- อย่าอัปโหลดไฟล์ JSON สำรองที่มีข้อมูลส่วนตัวลง GitHub แบบ Public

## เริ่มในเครื่อง
`pip install -r requirements.txt`
`streamlit run app.py`
