# ข้าวแกง 40 — V3

Streamlit เว็บแอปบน Android สำหรับร้านข้าวแกง จัดรายการวันละ **5 เมนู** 7–30 วัน:

1. ผัดจืด / ผัดผัก
2. ผัดเผ็ด
3. แกง
4. ต้มจืด
5. ยำ / ผัดไข่ (สลับวันตามลำดับวันในปฏิทิน)

มีคลังไอเดียอาหารเริ่มต้น 50 เมนู (รวม 5 เมนูของร้าน), เพิ่มชื่ออาหารและลิงก์สูตรจากภายนอกได้, แก้ไขตารางรายวัน, ดาวน์โหลด CSV และสำรอง/นำเข้า JSON V1–V3

**ยังไม่มีการค้นและนำเข้ารายละเอียดสูตรอัตโนมัติ**: เปิดผล Google/YouTube แล้วคัดลอกชื่ออาหารและลิงก์มาเก็บในคลังเอง

**ยังไม่มีฐานข้อมูลถาวร**: Streamlit Session State จะหายเมื่อ session สิ้นสุด ต้องดาวน์โหลด JSON สำรองทุกครั้งหลังแก้ไขข้อมูลสำคัญ

## Deploy บน GitHub เดิม

แทนที่ `app.py`, `requirements.txt`, `README.md` ใน root ของ repo เดิมบน branch `main` แล้ว commit; Streamlit Community Cloud จะอัปเดตโดยไม่ต้องสร้างแอปใหม่
